# Face Mask Detection Using Machine Learning

**Type:** Minor project · Third year · 2022  
**Technologies:** Python, OpenCV, Machine Learning  
**Team:** Collaborative four-member college team

## Overview
A face-detection project that explored machine-learning algorithms for detecting faces and identifying mask usage. The project was considered for security, authentication and surveillance-related applications.

## Scope
- Work with face-detection concepts.
- Explore machine-learning approaches to the detection task.
- Use Python and OpenCV as part of the project.
